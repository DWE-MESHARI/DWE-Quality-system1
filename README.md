# نظام إدارة الجودة

تطبيق React/Vite عربي باتجاه RTL لإدارة جودة خدمة العملاء. يحتوي على:

- لوحة التحليل ونبض الأداء
- التقييمات مع الإضافة والتعديل والحذف
- الإدخال الجماعي
- إدارة الموظفات والحالات والتقارير
- التقرير الشهري الرسمي مع الطباعة أو الحفظ كـ PDF من نافذة الطباعة
- سجل التغييرات مع التصدير
- إعدادات الأوزان والأهداف وحدود التقييم
- تصدير واستيراد نسخة احتياطية بصيغة JSON
- شاشة دخول متجاوبة بتصميم Clayful

## التشغيل

من جذر المستودع:

```bash
pnpm install
pnpm --filter @workspace/clayful-quality run dev
```

هذه النسخة تعمل بوضع عرض تجريبي، وتحفظ تعديلات الجلسة في الحالة المحلية للواجهة. ملفات Firebase الأصلية موجودة في مجلد `legacy-source` داخل حزمة GitHub، ويمكن استخدامها لاحقاً لربط المصادقة وFirestore بشكل فعلي.

## النشر

يمكن بناء التطبيق باستخدام:

```bash
PORT=5000 BASE_PATH=/clayful-quality/ pnpm --filter @workspace/clayful-quality run build
```

إذا تم نشره على GitHub Pages، اضبط قيمة `BASE_PATH` على مسار المستودع.
