قم بتحديث نظام إدارة وتقييم الموظفين الحالي وإضافة الميزات والتحسينات التالية بشكل كامل واحترافي، ثم قم بتجهيز المشروع كملف ZIP كامل وجاهز للرفع على GitHub:

1. الهوية والتصميم البصري (Design & Theme):
- توحيد الألوان للنظام بالكامل لتعتمد على لونين أساسيين فقط: البرتقالي الفاتح (Light Orange) والأبيض، مع درجات هادئة وعصرية متناسقة للنصوص والحدود.

2. لوحة التحليل والإحصائيات (Analytics Dashboard):
إضافة لوحة تحليلات متكاملة تتضمن:
- المؤشرات الرئيسية (KPIs): متوسط الأداء العام، متوسط الجودة (Quality Rate)، والمتوسطات لجميع المقاييس المسجلة.
- مؤشر موظف الفترة وتحقيق الأهداف: نسبة الأداء وتتبع تحقيق الأهداف الفردية والجماعية.
- أبرز النتائج والتحليلات: ملخص تنفيذي لأهم نقاط القوة والفرص التحسينية.
- الرسوم البيانية: تحليل بياني لتقسيم الموظفين، ورسم بياني لمسار تطور الأداء عبر الزمن.
- قائمة ترتيب الموظفين (Leaderboard / Ranking) بناءً على النتائج.
- التصفية والطباعة: إمكانية تحديد الفترة الزمنية (تاريخ بداية ونهاية) واختيار موظف محدد أو الكل.
- جعل لوحة التحليل بأكملها قابلة للطباعة بتنسيق مرتب، أنيق، ومطابق للغة التصميم الخاصة بالنظام.

3. الإدخال الجماعي والتحكم بالاستراحات (Bulk Entry & Break Tracking):
- توسيع خيارات الإدخال الجماعي لتشمل: عدد المكالمات، تقييم الجودة (Quality)، والمؤشرات الأخرى.
- إضافة ميزة تتبع الاستراحات (Breaks):
  * إمكانية تحديد الحد المسموح للاستراحة من صفحة الإعدادات (مثلاً: 60 دقيقة).
  * تسجيل وقت الاستراحة اليومي لكل موظف.
  * ترميز زمني ملون (Color-coded indicators): 
    - أخضر: إذا كان الوقت المستهلك أقل من أو يساوي المسموح (مثال: 30 دقيقة).
    - برتقالي: إذا وصل للحد المسموح تماماً (مثال: 60 دقيقة).
    - أحمر: إذا تجاوز الحد المسموح (مثال: 90 دقيقة فما فوق).

4. تقارير الموظفين والتقرير الشهري الرسمي (Reports & Exporting):
- تقرير الموظف الفردي: إمكانية تحديد فترة زمنية لعرض كافة التقييمات والسجلات الخاصة به، مع خيار طباعة التقرير بتنسيق مميز ومنظم.
- التقرير الشهري الرسمي للإدارة: إنشاء نموذج تقرير شهري شامل لكل التفاصيل والمؤشرات، بتنسيق وألوان احترافية ومجهزة للتقديم المباشر للقيادة والإدارة العليا.

5. متطلبات التجهيز والتسليم (Deliverables & Code Quality):
- قم بإنشاء هيكلية مشروع ويب بسيطة ومنظمة (Standard Static Web Project) تحتوي على:
  * index.html (الهيكل والواجهات)
  * style.css (التنسيقات وقواعد الطباعة @media print)
  * script.js (المنطق البرمجي والرسوم البيانية)
  * README.md (شرح للمشروع وطريقة التشغيل والرفع على GitHub)
  * .gitignore (استبعاد الملفات غير الضرورية)
- يرجى التأكد التام من صحة الأكواد وخلوها من الأخطاء البرمجية وأن جميع الميزات والرسوم البيانية والطباعة تعمل بشكل صحيح وسلس.
- بعد إتمام الأكواد والتحقق منها، قم بتجميع كل ملفات المشروع داخل أرشيف مضغوط بصيغة ZIP وإتاحة رابط تحميله لي مباشرة لرفعه على GitHub أو تفعيل GitHub Pages فوراً.
